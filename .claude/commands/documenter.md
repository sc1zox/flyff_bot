# Documenter Command

Perform administrative documentation updates after verified task completion:
1. Mark satisfied criteria `- [x]` in the user story or bug file.
2. Update frontmatter status (`completed` / `resolved`) and date.
3. Move file to `docs/user-stories/completed/` or `docs/bugs/fixed/`.
4. Update `docs/wiki/` and `docs/wiki/log.md` if architectural knowledge changed.
