# Write Story / Bug Command

Execute the story/bug creation workflow:
1. Interview the user to clarify requirements, scope, safety boundaries, edge cases, and localization.
2. Validate against existing stories, bugs, and wiki pages to determine the next ID.
3. Write the story (`docs/user-stories/US-XXX-kebab-title.md`) or bug (`docs/bugs/BUG-XXX-kebab-title.md`) adhering to project templates.
4. Commit the new story or bug file.
