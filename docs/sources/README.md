# Raw sources

This is the immutable evidence layer of the LLM wiki. Add locally captured requirements, server
rules, API documentation, screenshots, transcripts, or research notes here before asking an agent
to ingest them.

Rules:

- Never edit a source after it has been cited by the wiki; add a newer source instead.
- Use a descriptive filename prefixed with `YYYY-MM-DD-`.
- Record the original URL, author/publisher, retrieval date, and license when applicable.
- Do not store secrets, credentials, personal data, copyrighted game assets, or the local client.
- Wiki pages cite sources with repository-relative Markdown links.
