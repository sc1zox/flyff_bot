# Project documentation

This directory is the durable context for humans and coding agents.

- [LLM wiki](wiki/index.md): maintained project knowledge and cross-links.
- [Raw sources](sources/README.md): immutable evidence used by the wiki.
- [User stories](user-stories/README.md): requested behavior and acceptance criteria.
- [Bugs](bugs/README.md): reproducible defects and regression criteria.
- [Architecture decisions](decisions/README.md): durable technical tradeoffs.

Chat is temporary. Decisions and facts that future work depends on belong here.
